# Как работает память между сессиями

Новая сессия должна знать, где остановилась прошлая, и вам не придётся объяснять это
заново. grillspec ведёт небольшой журнал на каждый проект и выдаёт каждой новой сессии
короткую **сводку для продолжения**.

## Что туда попадает

| Запись | Кто пишет | Когда |
|---|---|---|
| `event` | CLI grillspec, автоматически | начато изменение, записано одобрение, задача плана прошла `exec done`, изменение ушло в архив |
| `handoff` | агент | перед концом сессии: что сделано, что дальше, что висит |
| `discovery` | агент | в момент, когда узнал что-то стоящее |
| `blocker`, `todo` | агент | когда что-то мешает работе или отложено на потом |

Агент пишет заметки одной командой, по одной строке:

```bash
grillspec note handoff -- "done: черновик спека; next: одобрить; open: лимит ретраев 3 или 5?"
grillspec note discovery -- "получатели отвечают 502 при пиковой нагрузке"
```

Никакой второй языковой модели, пересказывающей ваши вызовы инструментов: заметки
пишет агент, который делал работу, события — сам grillspec. Это ничего не стоит сверху,
работает без интернета и в любом харнессе — включая GigaCode на машине без сети.

## Что видит новая сессия

Сводка — не больше 1 500 оценочных токенов: активное изменение и его фаза, затем
закреплённые записи, последняя передача (handoff), открытые блокеры и todo и последние
события. Записи, которые не помещаются, выпадают целиком, а не обрезаются. Claude Code,
Cursor, Codex и Antigravity получают её при старте сессии; в GigaCode агент один раз
запускает `grillspec recall --brief`. Всё остальное — через поиск:

```bash
grillspec recall ретраи задержка      # полнотекстовый поиск с ранжированием
grillspec recall --pin 12             # всегда показывать #12 в сводке
grillspec recall --forget 7           # удалить #7 насовсем
```

## Интерфейс

`grillspec ui` открывает в браузере страницу с лентой по сессиям, изменениями и их
фазами, поиском и кнопками «закрепить» и «удалить». Она работает на 127.0.0.1, пока
открыт терминал, требует токен из ссылки, которую печатает команда, для каждого
запроса и ничего не загружает из сети. Ctrl+C её останавливает.

## Где лежит и приватность

Журнал — `.grillspec/journal/memory.db` (SQLite) в вашем проекте. Эта папка сама себя
исключает из git, поэтому журнал остаётся на этой машине и никогда не коммитится.
Устойчивые факты для всей команды по-прежнему место в блоке памяти в `AGENTS.md` (см.
[Как работает память](memory.md)).

Перед сохранением текст в `<private>…</private>` выбрасывается, а секреты — API-ключи и
токены, bearer- и JWT-токены, приватные ключи, значения вида `password=` — становятся
`<redacted>`. Вывод команд и содержимое файлов не сохраняются никогда, и ничего никуда
не отправляется. Выключателя у этих правил нет. Автоматически ничего не удаляется:
сводка берёт свежее и закреплённое, старое остаётся доступным через поиск.
