# Документация grillspec

grillspec превращает запрос в прогриленный журнал решений, спек, план и
протестированный код. У каждого механизма ниже одна причина существовать и своя цена
в контексте; цена каждого скилла — в [Сколько grillspec стоит в токенах](tokens.md).

| Механизм | Страница | Зачем он нужен |
|---|---|---|
| Бутстрап | [Как работает бутстрап](how-it-works/bootstrap.md) | Скилл, о котором агент не знает, никогда не срабатывает. |
| Гриль | [Как работает гриль](how-it-works/grilling.md) | Дизайн на догадке стоит дороже десяти лишних вопросов. |
| Council | [Как работает council](how-it-works/council.md) | Независимые перспективы ловят то, что пропускает одна линия рассуждений. |
| Спеки | [Как работают спеки](how-it-works/specs.md) | Требования с ID сценариев связывают тесты с решениями. |
| Память | [Как работает память](how-it-works/memory.md) | Факт, выясненный однажды, не должен выводиться заново в каждой сессии. |
| Планы | [Как работают планы](how-it-works/plans.md) | План хранит решения, которые исполнитель не может принять сам. |
| Выполнение | [Как работает выполнение](how-it-works/execution.md) | Задачи test-first и свежее ревью держат код верным спеку. |
| Архив | [Как работает архив](how-it-works/archive.md) | Живые спеки остаются записью того, что делает система. |
| Ворота между фазами | [Как работают ворота](how-it-works/gates.md) | Код, написанный до одобрения спека, — догадка. |
| Цена в токенах | [Сколько grillspec стоит в токенах](tokens.md) | «Стоит немного» должно быть числом. |

Также: [Установка](installation.md) · [Настройка](configuration.md)
