# Сколько grillspec стоит в токенах

Всё, что grillspec кладёт в контекст агента, либо **всегда включено** — оплачивается в
каждой сессии, — либо **по требованию** — оплачивается, только когда скилл
используется. Скиллы написаны по-английски, потому что неанглийский текст стоит больше
токенов при каждой активации; эта документация в агента не загружается, поэтому два
языка ничего не стоят.

## Оценки

`grillspec tokens` оценивает каждую часть по её размеру в UTF-8: байты ÷ 4.5 с
округлением вверх. Коэффициент откалиброван по измеренной сессии (ниже). Таблица
генерируется; CI падает, если она отстала от скиллов.

Справочные файлы скилла — это остальные файлы в его папке; агент читает их, только
когда скилл к ним отсылает. Блок памяти вашего проекта в `AGENTS.md` тоже всегда
включён: `grillspec tokens --project` добавляет его в расчёт.

## Измерено

`tests/benchmark/overhead.sh claude` запускает простейший промпт в пустом репозитории
с grillspec и без него и вычитает входные токены, которые сообщает харнесс
(`input + cache creation + cache read`).

| Дата | Харнесс | Без | С | Накладные |
|---|---|---|---|---|
| 2026-10-18 | Claude Code 2.1.287 | 45,373 | 47,469 | 2,096 |

Накладные — это роутер, строка статуса и каталог скиллов; они совпадают с оценкой с
точностью до нескольких токенов.

## Обновление

- После изменения скилла: `uv run python scripts/check_tokens.py --write`.
- После обновления харнесса или модели: запустите бенчмарк и добавьте строку.
