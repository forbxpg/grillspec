# Конфигурация

grillspec читает два TOML-файла и сливает их **по ключам**: проектный файл важнее
пользовательского, а тот — встроенных значений по умолчанию.

| Уровень | Путь | Что обычно там |
|---|---|---|
| Проект | `.grillspec/config.toml` (коммитится) | решения команды: бэкенд спеков, язык артефактов |
| Пользователь | `$XDG_CONFIG_HOME/grillspec/config.toml`, иначе `~/.config/grillspec/config.toml`; на Windows `%APPDATA%\grillspec\config.toml` | личные умолчания: глубина гриля, состав council |

## Ключи

```toml
version = 1

[spec]
backend = "openspec"          # openspec | superpowers — задаёт init
artifacts_language = "auto"   # auto | тег языка, например en, ru

[grill]
depth = "standard"            # quick | standard | deep

[council]
enabled = "ask"               # ask | yes | no
members = []                  # например ["role:devil", "role:simplicity", "cli:gemini"]

[gates]
enabled = true
```

| Ключ | По умолчанию | Значение |
|---|---|---|
| `spec.backend` | не задан до `init` | `openspec`: живые спеки в `openspec/specs/` и папка на каждое изменение. `superpowers`: один датированный спек и один план на изменение в `docs/grillspec/`. |
| `spec.artifacts_language` | `auto` | Язык спеков и планов. `auto` следует языку существующих документов проекта, а в пустом репозитории — языку разговора. Ключевые слова OpenSpec в любом случае остаются английскими. |
| `grill.depth` | `standard` | Глубина гриля: `quick` спрашивает раундами с бюджетом около 5 вопросов, `standard` — по одному, около 15, `deep` — без бюджета. Изменение начинается в фазе `grill` (`grillspec new`) и выходит из неё по `grillspec approve grill`; см. [Как работает гриль](how-it-works/grilling.md). |
| `council.enabled` | `ask` | Советоваться ли во время гриля с council независимых перспектив; `ask` спрашивает в начале каждой сессии гриля. |
| `council.members` | `[]` | Участники council по умолчанию. |
| `gates.enabled` | `true` | Активны ли ворота между фазами. |

## Ключ `version`

Каждый файл grillspec содержит `version = 1`. Файл с другой версией отклоняется с
сообщением, где назван файл, — старый grillspec никогда не прочитает новый формат неверно.

## Предупреждения и ошибки

- **Неизвестный ключ** → предупреждение с ключом и файлом; grillspec продолжает работу.
  Конфиг от более новой версии не ломает старую.
- **Недопустимое значение** (например `depth = "extreme"`) → ошибка с ключом, файлом и
  допустимыми значениями.
- **Битый TOML** → ошибка с файлом и строкой.

На старте сессии ошибки никогда не блокируют агента: они попадают в контекст как
предупреждения (см. [Как работает бутстрап](how-it-works/bootstrap.md)).
